# Architecture decision log

## ADR-001 — Monorepo
**Proposed/accepted for scaffold:** one repository with `apps/web`, `apps/api`, `infra`, `docs`, to keep UX/API contract changes together.

## ADR-002 — Initial stack
**Proposed for first iteration:** React/TypeScript/Vite, Spring Boot/Java 21, PostgreSQL. Reassess after first user stories; don't add unnecessary infrastructure.
